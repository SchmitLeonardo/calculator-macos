# 📱 Calculadora iOS (macOS / Web)

Um projeto desenvolvido em JavaScript, HTML e CSS para recriar a interface e as funcionalidades da calculadora nativa do iOS / macOS.

![Commits](https://img.shields.io/github/commit-activity/m/SchmitLeonardo/calculator-macos?style=flat-square)

---

## 📌 Sobre o Projeto

Este repositório contém uma aplicação web que simula o visual e o comportamento da **calculadora nativa do iOS/macOS**. O foco principal foi recriar com precisão o design limpo da Apple, o layout responsivo dos botões e a lógica de operações matemáticas básicas.

---

## ✨ Funcionalidades

- ➕ Operações básicas: Adição, Subtração, Multiplicação e Divisão.
- 🧮 Cálculo de porcentagem (`%`).
- 🔄 Inversão de sinal (`+/-`).
- 🧹 Botão de limpeza (`AC` / `C`).
- 🎨 Interface inspirada no design oficial do iOS/macOS.
- 📱 Layout responsivo e adaptado para diferentes telas.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** — Estruturação semântica dos elementos.
- **CSS3** — Estilização, layout (Flexbox/Grid) e efeitos visuais similares aos dispositivos Apple.
- **JavaScript (ES6+)** — Lógica das operações matemáticas e manipulação do DOM.

---

## 🚀 Como Executar o Projeto

Você não precisa de dependências externas nem de instaladores para rodar o projeto localmente.

### Prerequisites

- Um navegador web atualizado (Chrome, Firefox, Safari, Edge, etc.).

### Passo a passo

1. **Clone este repositório:**
   ```bash
   git clone https://github.com/SchmitLeonardo/calculator-macos.git
   ```

2. **Acesse a pasta do projeto:**
   ```bash
   cd calculator-macos
   ```

3. **Abra o arquivo principal:**
   - Basta dar um duplo clique no arquivo `index.html`, ou abrir diretamente pelo navegador de sua preferência.
